# 详情页返回逻辑与管理入口规范 V1

> 内部开发文档，不在科研系统页面展示。

## 统一规则

1. 综合查询进入项目详情、成果详情、教师画像时，附带 `return_url`。
2. 项目详情“返回上一页”优先回到 `return_url`；没有来源时退回综合查询。
3. 成果详情“返回上一页”优先回到 `return_url`；没有来源时退回综合查询。
4. 项目详情“进入项目管理”固定进入 `/project/`。
5. 成果详情“进入成果管理”固定进入 `/achievement/`。
6. 教师画像如果由综合查询或详情页进入，则“返回教师目录”优先返回来源页；没有 `return_url` 时保留原页面既有行为。
7. 不通过宽泛 DOM 重写页面，不改变页面主体结构，不修改业务数据。
