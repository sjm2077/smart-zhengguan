# 科研系统页面职责与导航规则 V1

> 内部开发文档，不在科研系统页面展示。

## 1. 核心原则

- 科研总览：首页工作台。负责发现问题、展示摘要、提供快速入口。
- 综合查询：唯一跨项目、成果、教师的统一检索中心。
- 综合详情：负责理解单个项目或成果，不承担业务编辑。
- 项目 / 成果 / 经费页面：负责对应业务对象的登记、编辑、维护和导出。
- 教师科研画像：唯一教师科研详情入口。
- 管理员智能分析：学院层风险、趋势和结构分析。
- 教师智能分析：教师个人科研辅助。
- 学科分析：学科层结构与发展分析。

## 2. 首页与综合查询边界

### 科研总览
保留：
- 核心科研 KPI；
- 全局快速检索入口；
- 查询摘要；
- 少量近期匹配记录；
- 待办与风险摘要；
- 学院总体趋势和结构图。

不承担：
- 完整项目 / 成果 / 教师结果列表；
- 复杂分页；
- 项目、成果的编辑删除；
- 完整风险处置表。

### 综合查询
保留：
- 跨项目 / 成果 / 教师检索；
- 年份、学科、教师、项目状态等筛选；
- 项目 / 成果 / 教师结果标签页；
- 分页；
- 单项详情入口；
- 查询条件保持和返回。

不承担：
- 新增、编辑、删除业务记录；
- 全院智能分析；
- 项目、成果业务管理。

## 3. 标准导航链

科研总览
→ 综合查询
→ 项目综合详情 / 成果综合详情 / 教师科研画像
→ 如需修改，再进入项目管理 / 成果管理 / 经费管理

风险：
科研总览风险摘要
→ 管理员智能分析
→ 风险项目
→ 项目综合详情
→ 项目管理

学科分析：
学科分析
→ 带条件综合查询
→ 综合详情

## 4. 返回规则

- 综合查询进入详情时，携带 return_url。
- 返回上一页优先恢复原查询参数、标签、页码。
- 不应从详情无条件跳回业务列表首页。

## 5. 禁止重复实现

- 首页不再维护第二套完整综合查询。
- 学科页不维护第二套项目 / 成果列表管理。
- 智能分析不维护项目 / 成果 CRUD。
- 各页面教师入口统一进入教师科研画像。
