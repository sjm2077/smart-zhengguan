科研项目新建/编辑功能接入说明
================================

一、文件清单
1. 科研项目_新建编辑功能版.html
   - 在现有科研项目页面上增加“新建项目”按钮、项目表单弹窗和详情页“编辑项目”按钮。
   - 保留原有筛选、图表、搜索、排序、分页、CSV 导出和详情展示。
2. views_项目管理API增强版.py
   - 基于本次上传的 views.py 完整版本增加项目表单选项接口和保存接口。
   - 项目详情接口额外返回 leader_id、dept_id，便于编辑时准确回填。
3. urls_项目管理API增强版.py
   - 增加 project/options 与 project/save 两条 API 路由。
4. 本说明文件。

二、替换前备份
先备份项目中的以下文件：
- templates/科研项目.html
- api/views.py
- api/urls.py

本次没有修改 models.py，不需要运行 makemigrations 或 migrate。

三、接入位置
1. 将“科研项目_新建编辑功能版.html”的内容替换到 templates/科研项目.html。
2. 将“views_项目管理API增强版.py”替换到 api/views.py。
3. 将“urls_项目管理API增强版.py”替换到 api/urls.py。
4. 如果你在上传本次文件之后又修改过 views.py 或 urls.py，不要直接覆盖；应将新增函数和两条路由合并到最新版本。

四、检查与启动
在项目根目录、已激活 Django 虚拟环境后执行：

python -m py_compile .\api\views.py .\api\urls.py
python manage.py check
python manage.py runserver 127.0.0.1:8000

五、功能验证
1. 使用管理员页面打开“科研项目”。
2. 点击“新建项目”，填写编号、名称、负责人、类型、状态、经费和起止日期后保存。
3. 确认新项目出现在列表中，统计图表能按后端数据刷新。
4. 点击项目名称打开详情，点击“编辑项目”，修改信息并保存。
5. 尝试重复项目编号、开始日期晚于结束日期、经费为负数等情况，确认后端返回校验错误。
6. 检查原有年份/学科筛选、搜索、排序、分页和 CSV 导出仍可用。

六、重要安全说明
当前页面的“管理员/教师”切换只依赖浏览器 localStorage，并不是真正的服务端身份认证。
本版本的写接口使用 Django 默认 CSRF 机制并做字段校验，但尚未加入服务端管理员权限验证。
因此，该版本只适用于本地开发/演示环境，不要直接部署到局域网或公网。正式部署前必须先接入真实登录，并在 project_save_api 中验证当前登录用户的管理员权限。
