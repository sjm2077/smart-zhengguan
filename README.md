# 智慧政管综合平台

面向山东大学政治学与公共管理学院的院级数字化治理平台。项目以统一主门户为入口，聚合教学管理、科研管理、人事管理和研究生管理四个独立业务子系统，并提供知识库问答、智能预警、师生画像、词云分析等公共能力，服务学院管理者、教师和学生等不同角色。

## 项目定位

平台用于把学院日常管理中的教学、科研、人事和学生培养信息集中展示和分模块管理。主门户负责统一导航、角色权限和综合数据大屏；各业务子系统保留相对独立的业务模型、接口和数据存储，便于不同成员并行开发和维护。

当前项目以可演示原型和业务系统联调为主，部分数据来自真实采集文件、业务数据库和导入表，部分页面仍使用演示或模拟数据。跨系统统一认证、统一数据口径和全面数据打通属于后续建设方向。

## 总体架构

```text
                         智慧政管综合平台
                                  |
                         Vue 主门户 / 数据大屏
                                  |
       +------------------+-------+-------+------------------+
       |                  |               |                  |
    教学管理           科研管理        人事系统           研究生管理
   Vue + Django       Django/HTML      Django + HTML       Vue + Django
       |                  |               |                  |
   教学数据           科研数据        人事 Excel          研究生数据库
                                  |

```

主门户通过路由和嵌入页面访问独立子系统。各模块可以单独启动、开发和测试；联调时按端口启动对应服务。

## 主要功能

### 主门户与综合大屏

- 综合概览：学生规模、教师数量、科研项目、经费和预算等 KPI，以及趋势、地图、词云和结构分析图表。
- 角色权限：支持院长、管理员、教务、科研、人事、研究生管理和学生等角色，按角色控制菜单和指标可见范围。
- 统一导航：从主门户进入教学、科研、人事、研究生四个业务系统。
- 公共页面：登录、个人中心、智能预警、师生画像、词云分析和校园树洞。

### 教学管理系统

覆盖认证、仪表盘、学生、课程、考试、成绩、质量分析、教师和通知等业务，支持教学数据维护、成绩与考试管理及教学质量分析。

### 科研管理系统

覆盖科研项目、经费、成果、教师评价、合作关系、院系资源和风险预警等业务，提供项目、经费、成果趋势、合作网络、词云和教师分析等统计页面及接口。

### 人事系统

基于 Django、Node.js 和原生 HTML/JavaScript，读取人事平台 Excel 数据，提供人员信息、岗位、职称、考核等人事数据展示，并包含面向管理者的“院长随手看”页面。

### 研究生管理系统

覆盖招生录取、学籍异动、培养计划、课程、学位、答辩、奖助、就业和风险管理等业务，支持 Excel 数据导入、统计分析、学生画像和就业信息管理，并包含预测与知识检索能力。

### 知识库与智能能力

- 知识库问答：检索学院官网、通知公告、教师信息、学术成果和制度文件，并返回来源引用。
- 智能预警：集中展示风险指标和待处理事项。
- 师生画像：展示教师或学生的基本信息、经历、标签和统计分析。
- 预测与 RAG：研究生系统提供规则预测和可选大模型增强问答；知识库服务提供基于关键词/BM25 的文档检索。

## 技术栈

| 层次 | 技术 |
| --- | --- |
| 主门户 | Vue 3、Vite、Vue Router、Pinia、ECharts |
| 教学前端 | Vue 3、TypeScript、Element Plus、ECharts、Axios |
| 教学后端 | Django、Django REST Framework、SimpleJWT |
| 科研系统 | Django、Django REST Framework、服务端模板、原生 HTML/JavaScript |
| 人事系统 | Django、Node.js、原生 HTML/JavaScript、openpyxl |
| 研究生系统 | Vue 3、Element Plus、ECharts、Django、DRF、SimpleJWT |
| 知识库服务 | Python 标准库、BM25 检索、CSV/JSON/HTML/Markdown/文档解析 |
| 数据存储 | SQLite、Excel、CSV/JSON；部分服务支持 MySQL |

## 本地运行概览

建议使用 Node.js 20+、Python 3.10+，并分别安装主门户和各子系统的依赖。各模块的详细环境要求以对应目录下的说明文件和 `package.json` 为准。

| 模块 | 常用地址 | 启动位置 |
| --- | --- | --- |
| 主门户 | `http://127.0.0.1:3000` | 根目录执行 `npm run dev` |
| 教学管理 | `http://127.0.0.1:5174` | `教学系统/frontend` 前端，配合教学后端 |
| 科研管理 | `http://127.0.0.1:8888` | `research_system` 执行 Django 启动命令 |
| 人事系统 | `http://127.0.0.1:3002` | `智慧人事系统` 使用项目启动脚本 |
| 研究生管理 | `http://127.0.0.1:3003` | `smartzhengguan` 前端和 `backend` 后端 |
| 知识库服务 | `http://127.0.0.1:8900` | `kb_service/server.py` |

主门户中的子系统地址和代理配置以 `src/router/index.js`、`vite.config.js` 及各子系统配置为准；端口被其他程序占用时，应同步修改对应的嵌入地址或代理配置。

## 数据与安全说明

- 仓库中的 Excel、CSV、JSON 和 SQLite 文件包含演示数据、采集数据或开发数据，使用前应确认数据来源和使用范围。
- 大模型密钥、数据库密码和其他敏感配置应放在服务端环境变量或 `.env` 文件中，不要提交到前端代码和 Git 仓库。
- 生产部署前应关闭调试模式，重新配置密钥、跨域、允许主机和数据库连接，并为真实数据设置访问权限。

## 项目状态

项目采用“主门户 + 独立子系统”的协作方式持续开发。各子系统可以由不同成员负责，在合入主分支前应完成本模块自测、接口变更说明和必要的数据迁移说明。
