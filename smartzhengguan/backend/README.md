# Django Backend

This directory contains the Django backend service for the graduate management system.

## Scope

- User authentication and account management
- Graduate student status and academic records
- Training plan and course management
- Scholarship, degree, defense, and employment modules
- Dashboard and report APIs
- Intelligent prediction analysis and chat APIs

## Local Setup

1. Create a virtual environment:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. Install dependencies:

   ```powershell
   pip install -r requirements.txt
   ```

3. Copy the environment template:

   ```powershell
   Copy-Item .env.example .env
   ```

4. Run migrations:

   ```powershell
   python manage.py migrate
   ```

5. Start the backend:

   ```powershell
   python manage.py runserver
   ```

## Load Demo Data

Load demo data from the frontend mock source:

```powershell
python manage.py seed_mock_data
```

Keep existing records and append demo data:

```powershell
python manage.py seed_mock_data --keep-existing
```

Import data from the Excel workbook:

```powershell
python manage.py import_excel_data
```

## Intelligent Prediction AI Configuration

To enable external AI for the intelligent prediction chat module:

1. Copy `.env.example` to `.env`
2. Set `PREDICTION_LLM_ENABLED=True`
3. Choose the API style:
   - `PREDICTION_LLM_API_STYLE=responses` for OpenAI `Responses API`
   - `PREDICTION_LLM_API_STYLE=chat_completions` for most OpenAI-compatible providers
4. Fill `PREDICTION_LLM_API_KEY`
5. Set `PREDICTION_LLM_MODEL` if you want a different model
6. Optionally set:
   - `PREDICTION_LLM_BASE_URL`
   - `PREDICTION_LLM_REASONING_EFFORT`
   - `PREDICTION_LLM_TEMPERATURE`
   - `PREDICTION_EXPOSE_DEBUG`
   - `PREDICTION_KNOWLEDGE_DIRS`

Example `.env` snippets:

OpenAI:

```env
PREDICTION_LLM_ENABLED=True
PREDICTION_LLM_PROVIDER=openai
PREDICTION_LLM_API_STYLE=responses
PREDICTION_LLM_API_KEY=sk-...
PREDICTION_LLM_BASE_URL=https://api.openai.com/v1
PREDICTION_LLM_MODEL=gpt-5-mini
```

OpenAI-compatible provider:

```env
PREDICTION_LLM_ENABLED=True
PREDICTION_LLM_PROVIDER=compatible
PREDICTION_LLM_API_STYLE=chat_completions
PREDICTION_LLM_API_KEY=your-api-key
PREDICTION_LLM_BASE_URL=https://your-provider.example/v1
PREDICTION_LLM_MODEL=your-model-name
```

Current behavior:

- Prediction analysis is still generated by backend rules and structured evidence
- Prediction chat can use either rule-based RAG or an external LLM
- Frontend runtime options already support:
  - `preferredModel`
  - `apiStyle`
  - `reasoningEffort`
  - `temperature`
  - `useLlmWhenAvailable`

If `PREDICTION_EXPOSE_DEBUG=True`, prediction endpoints will also return prompt debug payloads for troubleshooting.
